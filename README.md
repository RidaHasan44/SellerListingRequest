# MIS3371-Marketplace-Listing
This repository contains the capstone project for team 21 for MIS 3371

Scenario:
A verified seller requests to post a clothing listing on an e-commerce marketplace. The system captures the product and seller information, checks listing requirements and policy rules, and routes eligible items for approval before posting.​

Project Purpose:
The purpose of this project is to simplify the online listing posting process for verified sellers on the online platform and marketplace. This project will provide a seamless and convenient experience for the platform users when uploading new listings. By improving product data validation and automating listing verification, the system aims to minimize interruptions, reduce submission errors, and accelerate listing approval times. Overall, the purpose of this project is to enhance the verified sellers' experience through verifying and authenticating data precision across the transaction.
